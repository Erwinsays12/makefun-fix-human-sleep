A tiny deterministic program for the make.fun competition
[Fix Human Sleep: Funniest Patch Note](https://make.fun/c/u-yuki-kato-fix-human-sleep-funniest-patch-note-f6ad4c27).

`main.ts` writes a single line of patch notes announcing that human sleep
has been fixed to `/output/entry.txt`:

> Fixed: sleep now installs correctly; users will no longer wake at 3 a.m. to replay every awkward thing they said in 2011.

The line is 121 characters — a real changelog voice ("Fixed: ... installs
correctly") with a specific, unexpected payoff: the 3 a.m. replay of every
awkward thing you ever said.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22+.
